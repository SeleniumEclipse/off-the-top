# Off the Top 1.3.0 — Flat color, clear controls

- Removed the gradient. Both themes now have solid backgrounds.
- Replaced font-character arrows and checkmarks with consistent Material vector icons.
- Removed decorative deck pictures, the phone illustration, deck subtitles and routine setting subtext.
- Kept clear action labels, necessary gameplay guidance, teal, and the existing fonts and borders.
- Added sourced design rules and tests to prevent gradients, emoji-style icons and filler copy returning.

**Download Off-the-Top-1.3.0.apk below and install over the existing app.** No uninstall needed; saved settings, history and played-card memory stay intact. Android 8.0+.

All three decks and 1,844 cards remain. Tilt behavior is unchanged. **134 unit tests and 22 Android tests passed.** Signed-APK checks cover real-time rounds, simulated sensor gestures and restart persistence. Physical-phone behavior still needs hands-on testing.
